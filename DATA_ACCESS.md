## Extended-hours validation

On 2026-10-28 at 21:42:57 UTC, the existing server-side account returned HTTP 200 from `/stable/aftermarket-trade` for AAPL: price 344.91, timestamp 1793223770000 (milliseconds; 21:42:50 UTC), tradeSize 5. This live access check preceded implementation of the extended-hours feature. The temporary check was removed afterward. Only AAPL was validated directly; other symbols may have different coverage. Official documentation: https://site.financialmodelingprep.com/developer/docs/stable/aftermarket-trade

Daily change is `(latest regular-session price / preceding trading observation close - 1) * 100`. Extended-hours change compares the separate trade price with the latest regular-session close. Extended trades never enter the daily OHLC bars, OBV or technical scores. A same-date, same-session trade is required; an unavailable or denied trade leaves the regular chart usable. One optional symbol request is cached for 60 seconds, only for current-date requests outside weekday 9:30–16:00 New York time (6:30–13:00 Pacific). Weekends and historical-only requests skip it. These are standard session-clock boundaries, not an exchange holiday/early-close calendar. Premarket displays only if FMP returns a qualifying current premarket trade. Price refresh remains manual via Load chart; the client hides extended quotes when the regular session begins, without polling FMP.

## Monthly universe and stock drill-down

The user requested monthly constituent/table persistence, automatic price refresh on navigation, and collapsed industry stock detail. Membership/classifications are now snapshotted on the first visit of each calendar month. Full per-stock histories are persisted for that month in bounded D1 chunks (up to 48 securities), using existing bindings/schema. Fresh quotes are requested on each page visit (up to 60-second quote/result cache), with four batch requests in flight at most. Page opening first shows a saved snapshot when available, then refreshes automatically.

Calendar-sensitive returns are not frozen monthly: a small benchmark history refresh establishes actual trading-date anchors, previous-close quotes add completed-session closes, and saved full histories supply older anchors. If a gap in visits leaves a needed recent date absent, only the missing stock/date ranges are fetched. Material inferred-share-count or stored-close discrepancies trigger a targeted full-history repair for the affected security rather than inventing split adjustments. Full member history downloads are otherwise monthly. Snapshots expose as-of dates, quote times, membership month, exclusions and cache mode. No background scheduler or new data endpoint is introduced.

Each industry now carries individual eligible stock price returns for the same seven periods. Stock rows are created lazily on expansion, remain collapsed on a new page visit, preserve expansion across price refreshes, and make no additional provider requests. Industry ranking still excludes stock rows. The review payload omits the redundant full eligible-member list to offset the stock-detail response size.
