# Forward Return Research

An independent client module receives a one-way `chart-range` event after the chart draws. It never changes the chart data, date inputs, selected period, zoom, sliders, drawing, indicators or network requests. Its collapsed panel is between the chart and Six Technical Components. The visible chart range selects signal dates; Full Loaded History is a separate matrix option. Episode boundaries and warmup use all loaded observations. A range starting mid-episode does not create a new event. The latest loaded reading is outlined even if it is outside the visible range; provisional current readings are labeled and excluded from historical outcomes.

The nine groups use the chart's configured strong/weak and lower/upper percentile thresholds (defaults 5–6, 2–4, 0–1 and ≤5, middle, ≥95). A missing score or percentile is not a group. Invalid readings break continuity. An episode starts when the group changes from the previous loaded observation; the first valid loaded state is counted as an episode and that load-boundary limitation should be considered when interpreting short downloads.

Forward horizons are 21/63/126/252 benchmark sessions, default 63. Close-of-session signals enter on the next session's stock and sector opens and exit on the horizonth session's closes. Excess return is stock price return minus sector ETF price return, in percentage points. Worst excursion is the minimum stock low relative to entry open, capped at zero; it is not peak-to-trough portfolio drawdown. Provisional prices, missing OHLC and unmatched stock/sector/benchmark sessions invalidate outcomes. Outcomes may extend beyond the visible chart range, but never beyond loaded completed prices. The existing history response adds sector date/open/close and benchmark calendar from already fetched histories; no extra FMP calls occur.

Cells show median excess return, completed outcomes and episode starts. Detail includes mean, median absolute return, outperformance frequency, median worst excursion, excluded outcomes and an approximate 95% median interval. All Days and Episode Starts are different estimands; the displayed unconditional baseline uses all valid-signal days and is explicitly not episode matched. Empty values are unavailable, never zero. There is no CAGR or trading-strategy claim.

Intervals use deterministic resampling of non-overlapping horizon-length calendar blocks (300 samples), preserving within-block clustered outcomes. They are suppressed below five occupied blocks; fewer than ten episode starts or five occupied blocks is marked Sparse. These are exploratory uncertainty summaries, sensitive to block length and not corrected for multiple testing or parameter selection. No statistical-significance badge or buy/sell recommendation is generated.

Research uses existing FMP open/close price fields; dividends, costs, cash returns and independent corporate-action certification are outside this initial price-return study. It uses the currently selected sector ETF across loaded history, not point-in-time sector classifications. The methods panel discloses these limitations. Recently-overbought conditions, chart overlays and cross-sectional alerts are deferred; the original chart remains unchanged apart from Title Case labels and the one-way event.

Regression checks cover chart presets, date fields/handles, zoom, ratio display, quote/after-hours behavior and score shading. Research tests cover exact bin boundaries, methodology overrides, next-open timing, maturity, missing sessions, range/episode boundaries, deterministic bootstrap, provisional exclusion, current-cell highlighting, independent controls and module routes. Preview uses fictional data only.
