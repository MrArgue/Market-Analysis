## Status and scope

Public `/macro` adds one shared US growth/inflation history and separate strategic and tactical views. This is an offline/importable research prototype, **not a validated live macro model**. No actual allocation rankings, current regime, total-return estimates or predictive efficacy are claimed. Local JSON import calculates entirely in the browser. Page opening makes no provider requests. The optional saved-input button reads one versioned key from the existing D1 cache. There is no ingestion writer, scheduler, production seed, migration or new binding. Anonymous users cannot launch provider jobs or write inputs. Diagnostics continue through the unchanged Access handler.

## Research rationale and source decisions

[AQR's macro-environment study](https://www.aqr.com/-/media/AQR/Documents/Insights/Alternative-Thinking/Alternative-Thinking-Mapping-Investable-Return-Sources-to-Macro-Environments.pdf) motivates examining asset and style exposures separately and cautions that empirical relationships depend on design and period. Its contemporaneous macro relationships do not validate forward tactical timing. The prototype tests forward conditional returns directly; it does not copy the paper's returns or claim replication.

[FRED real-time periods](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html) distinguish what is known today from what was known historically. [Observation API documentation](https://fred.stlouisfed.org/docs/api/fred/series_observations.html) describes real-time boundaries and vintage queries. Ordinary FRED current-history CSVs are **not** accepted as historical vintage evidence. Authenticating successfully is not proof of complete point-in-time coverage. The Philadelphia Fed's [real-time data research](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research) is a cross-check candidate for revisions and initial releases, not an implemented replacement.

| Candidate | Timing and availability | Prototype decision / evidence |
|---|---|---|
| INDPRO / PAYEMS / W875RX1 | Monthly production, payrolls, real income excluding transfers; revised and released after observation period | Equal-weight growth axis, conditional on validated ALFRED vintages. INDPRO current CSV tested; all historical vintage entitlement remains unverified. |
| CPIAUCSL / PCEPILFE / PPIACO | Monthly headline CPI, core PCE, commodity PPI; different breadth, release schedules and seasonal adjustments | Equal-weight inflation acceleration axis; CPI is one component rather than the sole signal. PPIACO is not seasonally adjusted and may introduce seasonality: a material v1 limitation requiring sensitivity work before live use. |
| [ICSA](https://fred.stlouisfed.org/series/ICSA) | Weekly claims with revisions; week-ending date is not publication date | Timelier growth candidate; fixed authenticated probe included, not blended into v1 without weekly aggregation/revision validation. |
| [T5YIE](https://fred.stlouisfed.org/series/T5YIE) | Daily market-implied average inflation over five years | Context candidate, not realized inflation; market prices create potential circularity with return analysis. Not a v1 component. |
| [Atlanta Fed GDPNow](https://www.atlantafed.org/research-and-data/data/gdpnow) | Published updates estimate current-quarter GDP; official site distinguishes historical archives from pre-live forecasts | Useful nowcast candidate. Archive parsing, model-history changes and release-timestamp replay untested; excluded from this frozen version. |
| [Chicago Fed CFNAI](https://www.chicagofed.org/research/data/cfnai/current-data) | Broad monthly activity index relative to trend | Alternative growth cross-check; current history alone does not establish release-aware vintage replay. Not included. |
| FMP dividend-adjusted ETF history | [Provider documentation](https://site.financialmodelingprep.com/how-to/fmp-historical-price-apis-from-light-charts-to-dividendadjusted-analysis) describes `/stable/historical-price-eod/dividend-adjusted` | Exact account access and `adjClose` payload unverified here. No fallback to ordinary chart closes. Independent adjustment reconciliation remains required even after HTTP/field checks. |

These choices favor auditable monthly acceleration over an unvalidated nowcast. They do **not** meet a claim of instantaneous or leading economic measurement. A timelier v2 must earn inclusion with historical release replay and frozen out-of-sample tests; changing weights or inputs creates a new model version shared by both return views.

## Frozen calculation contract

Version `macro-growth-inflation-v1` covers the series list, transformation, availability convention, normalization, weights and regime rules. Monthly cutoffs must be consecutive month ends at 23:59:59 UTC. Raw macro rows contain `series`, observation `period`, revision `vintage`, UTC `availableAt`, positive numeric `value`. Vintage date is not observation date. Conflicting same-series/period/vintage values are rejected. Keep raw response hashes, source URLs without secrets, retrieval times, query parameters and release verification in the dataset provenance; the browser cannot authenticate a user's provenance assertions.

At each cutoff, select the latest eligible vintage for each observation period. Date-only ALFRED information is eligible no earlier than the **following UTC day**; if source release/ingestion time is later, use that later time. This conservative rule avoids assuming intraday publication precision. Do not backdate first retrieval of a current-only series. Historical ingestion must verify that vintage metadata actually reconstructs knowledge then. No current-history revisions may be labeled as historical initial releases.

For seven consecutive monthly levels `x0..x6`, momentum is `100*((x6/x3)^4-1) - 100*((x3/x0)^4-1)`. Each component is standardized using its **previously frozen decision-time** momenta (minimum 24 valid prior decisions, trailing 60 valid decisions), population standard deviation, clipped to ±3. Missing historical decision readings do not count toward warmup. A constant prior sample yields unavailable, not zero. Both axes are equal means of all three required standardized components. No opportunistic reweighting around missing data. A component whose latest observation period is more than 100 days behind cutoff or has a gap in its seven-month window is unavailable. These are proposed research parameters, not tuned performance results.

Signs identify Goldilocks (+growth, −inflation), Reflation (+,+), Stagflation (−,+), Slowdown (−,−). Either axis within ±0.15 is an explicit Transition state; missing axes are Unavailable. All six transformations, selected source vintages, standardized components, cutoff and model version are exposed in the audit. Current reading uses the last supplied decision cutoff, not an asserted live reading. Future revisions cannot change an already computed earlier cutoff.

## Separate return estimands and inference

Strategic: calendar horizons **6 and 12 months**, absolute ETF total-return proxy plus arithmetic excess return in percentage points over its explicitly named cash ETF. Tactical: **1, 3 and 6 months**, ETF total-return difference versus its explicitly named equity benchmark. A dataset must explicitly declare `basis: dividend-split-adjusted` and `coverageVerified: true` on both asset and benchmark; this is an operator attestation, not automated economic certification. No unadjusted price substitution, annualization or CAGR. Close-only adjusted histories enter at the first trading session **strictly after** decision date, at that session's close. Exit is the first completed session on/after the calendar-month anniversary, clamped at month end. This intentionally adds a full session of implementation delay rather than pretending an adjusted open is available.

Use an independently verified completed-session exchange calendar. Missing asset or reference prices anywhere on the holding path, provisional prices, nonpositive endpoints, pre-inception history and immature horizons exclude the outcome. No forward-filled prices. A calendar omitted session cannot be detected from prices alone: calendar provenance is part of the coverage review. `asOf` bounds completed calendar dates. Duplicated asset dates, calendar disorder, mixed model versions and invalid settings fail closed.

Episode Starts and All Decision Months are separate sampling estimands. Episodes are defined over all supplied decisions before filtering; an unavailable reading breaks continuity. The first supplied state is a load-boundary episode, so provide adequate prehistory and disclose truncated samples. Warmup history cannot be inferred from a later slice. Baseline is unconditional across the same eligible regime/transition decisions and same sampling mode; it is not silently an all-day baseline for an episode sample. Per-cell counts show completed, excluded, episode starts and occupied horizon blocks. Audit includes each excluded reason (basis, immature, missing), dates, individual outcomes and baseline.

Mean, median, positive-return/outperformance frequency, mean excess and a descriptive 95% median block interval are reported. Resampling uses the existing deterministic 300-replicate block routine on **decision-month indices**, with blocks as long as the horizon. Overlapping returns remain dependent within blocks. Fewer than five occupied blocks suppresses intervals; fewer than ten outcomes is Sparse. Occupied blocks are a dependence diagnostic, not an exact effective sample size. Horizon length is an unvalidated block-length choice; block-length sensitivity, structural breaks, serial dependence beyond the horizon and selection of rare episodes can materially change uncertainty. There are no p-values, significance badges, optimized allocations, multiple-comparison corrections or forecast probabilities. Forward-return sorting is descriptive in-sample research until frozen holdout/walk-forward analysis with realistic costs is completed.

## Review and local use

`node scripts/macro-example.mjs <output.json>` creates a deterministic **fictional** import file. Its weekday-only calendar and synthetic adjusted levels are for interface review, never empirical evidence. Start the existing local Worker, visit `/macro`, and select that JSON. The tactical selector changes horizons and estimands without changing the model. The calculation/audit panel exposes inputs, results, coverage and baseline. Imported strings render as text, not HTML. Files over 5 MB are rejected, and model/return row limits bound local work. Read-only saved input uses `macro-growth-inflation-v1:reviewed-inputs` in existing `market_history_cache`; no input is seeded by this change. Publishing a reviewed snapshot is separate operational work requiring a concrete review of provenance and coverage.

Preserved: Cloudflare Worker/D1 bindings and schema, public chart/research access, protected diagnostics, existing technical formulas, original chart return assumptions and server-side credentials. No merge, deployment, production read/write, migration or large provider batch was performed. Production usefulness and coverage remain blocked on credential-enabled validation and reviewed historical ingestion.
